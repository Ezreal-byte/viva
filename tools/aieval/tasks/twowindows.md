A two-window app: the main window (640x420) has a title 'Documents', a list of three documents as clickable rows and an 'Open inspector' button. The button opens a second window (360x300) titled 'Inspector' that shows the name of the document selected in the main window and a 'Close' button that closes only that window. Selecting another document in the main window updates the open inspector. Closing the main window ends the program.
