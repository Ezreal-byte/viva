A preferences page, 560x520, title 'Preferences', two sections with a bold heading each. 'Display' has one row 'Font size': the name on the left and, at the right end, a stepper: a 'Smaller' button, the value '14 px' in a fixed-width centered box, a 'Larger' button. Each press changes it by 2 px, between 10 and 24 (the button that would pass the limit is disabled). 'Sound' has a row 'Volume' built the same way with 'Quieter' and 'Louder' buttons, the value shown like '50%', steps of 10, between 0 and 100. Below the sections a 'Reset to defaults' outline button. Pressing it does not reset at once: it asks 'Reset all settings?' with a 'Yes, reset' (destructive) and a 'Keep settings' (outline) button; Yes puts both values back to 14 px and 50% and dismisses the question, Keep dismisses it and changes nothing. The defaults are 14 px and 50%.
