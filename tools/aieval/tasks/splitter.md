A two-pane page, 800x500: on the left a 'Files' pane (a heading and six file names), on the right a 'Preview' pane (a heading and a paragraph). Between them is a vertical splitter bar the user drags with the mouse to change the width of the left pane (the right pane takes the rest); the pointer shows a horizontal-resize cursor over the bar and the left pane is kept between 120 and 500 wide.
